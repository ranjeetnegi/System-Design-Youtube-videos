# Video Scripts — System Design YouTube Series

A collection of video scripts for a System Design YouTube series. Each script is structured for ~4–5 minute videos with clear hooks, analogies, diagrams, and real-world examples.

## Structure

Scripts follow a consistent format:

- **Hook** — Short, engaging opener (20–30 seconds)
- **Story / Explanation** — Core concept with analogies
- **Diagrams** — ASCII diagrams for visual learners
- **Real Examples** — Industry examples (Netflix, Uber, etc.)
- **Summary** — Key takeaways

## Naming Convention

```
Topic_XXX_Topic_Name.md
```

- `XXX` — Topic number (e.g., 001, 065, 303)
- `Topic_Name` — Descriptive name with underscores

## Quick Start

1. Browse topics by number or category above.
2. Open any `Topic_*.md` file to read the full script.
3. Scripts include video length and difficulty level (Beginner / Intermediate).
